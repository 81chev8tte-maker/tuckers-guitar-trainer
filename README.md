# Tucker's Guitar Quest

A free Chromebook-friendly PWA that teaches beginner electric guitar as a game.

## v0.2.0

- Falling-note Guitar Hero/Rocksmith-style missions
- Live microphone / USB audio-input pitch detection
- Hit, miss, timing, combo, accuracy, score, XP and 1–3 star ratings
- Locked mission progression across three beginner worlds
- "Tab Decoder" world teaches tablature while Tucker plays it
- Live six-line tab strip mirrors every falling note
- Guitar-input test screen with device selector and noise gate
- Chromatic tuner, metronome and chord reference
- Local Guitar Pro / MusicXML / text-tab library and alphaTab practice player
- Offline-friendly PWA shell

## Guitar input

The app works with the Chromebook microphone listening to a clean amp, but a USB guitar/audio interface should provide cleaner and more reliable note detection. Browser microphone permission is required.

Imported song files and progress remain in browser storage on the device.
